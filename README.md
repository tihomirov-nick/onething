# One Thing

One Thing держит в строке меню одну фразу: главное дело на сегодня. Текст виден в любом приложении весь день. Значка в Dock у приложения нет. Пока фразы нет, в строке меню стоит маленький знак, открывающая кавычка.

Левый щелчок по фразе открывает окошко с одним полем ввода. Return сохраняет фразу, Esc закрывает окошко без изменений, пустая фраза возвращает знак. Правый щелчок или щелчок с Control открывает меню: «Настройки…» ⌘,, «Проверить обновления…», «О приложении «One Thing»» и «Завершить One Thing» ⌘Q.

## Настройки

Раздел «Фраза» под «Основными» и «Обновлениями»:

- Максимальная ширина текста в строке меню, от 80 до 400 pt. Фраза длиннее обрезается многоточием, целиком её видно в подсказке к значку и в окошке.
- «Скрыть текст» оставляет в строке меню только знак. Фраза сохраняется.
- Шрифт: «Системный» по умолчанию или любое установленное семейство. Список с поиском, каждое семейство набрано собственным шрифтом. Начертание (обычное, полужирное, курсив, полужирный курсив) предлагается из тех, что есть у семейства. Поле ввода в окошке набрано тем же шрифтом, так что видно, как фраза будет выглядеть. Если выбранный шрифт пропал из системы, приложение молча возвращается к системному, а сам выбор остаётся: вернётся шрифт, вернётся и он.
- Сочетание клавиш для правки открывает окошко с полем из любого приложения. По умолчанию его нет. Нажмите на кнопку и введите сочетание, Esc отменяет, ⌫ убирает.

## Как устроено

Фраза, ширина, «Скрыть текст», шрифт и сочетание лежат в UserDefaults (`phrase`, `maxWidth`, `hideText`, `fontFamily`, `fontStyle`, `editShortcut`). Значок в строке меню следует за любым изменением.

Текст в строке меню приложение рисует само, в шаблонное изображение высотой с строку меню (`MenuBarText.swift`). Базовая линия у любого шрифта стоит там же, где у системного текста строки меню. Обычный заголовок кнопки центрирует строку шрифта целиком, и базовая линия сдвигалась бы вместе с метриками шрифта. Размер текста тот же, что у системного, ширина ограничена настройкой. Обрезка и рисование измеряют текст одной функцией, поэтому результат всегда укладывается в заданную ширину.

Чистая логика без AppKit лежит в `Sources/OneThingCore`: `Phrase.swift` (очистка текста, обрезка по ширине, настройки), `FontChoice.swift` (выбор шрифта), `KeyValueStore.swift` (хранилище, которое в тестах живёт в памяти и не оставляет файлов). Тесты проверяют обрезку, сохранение, выбор шрифта и откат к системному, положение базовой линии.

`AppActions.isBusy` равен «окошко с полем открыто»: пока оно открыто, автообновление ждёт и не перезапускает приложение. Сочетание клавиш работает через Carbon (`RegisterEventHotKey`), разрешения не нужны.

## Что где лежит

Своё приложение пишет в `Sources/OneThing/AppParts.swift`, остальной код в `Sources/OneThing` общий для семьи.

- `AppParts.swift`: знак для пустой фразы (`MenuBarIcon.drawGlyph`), окошко `MainView`, раздел «Фраза» в настройках, действия меню (пусто, меню стандартное) и `isBusy`.
- `PhraseField.swift`: поле ввода окошка и черновик фразы.
- `PhraseFont.swift` и `FontPicker.swift`: шрифт фразы, выбор шрифта и начертания.
- `MenuBarText.swift`: как фраза рисуется в строке меню.
- `Hotkey.swift`: глобальное сочетание клавиш и его запись.
- `Glyph.swift` и `OneThing.swift`: знак, правила рисования общие для семьи утилит. Те же два файла продублированы в `scripts/make_icon.swift`, который рисует иконку и запускается одним файлом. Тест следит, чтобы копии не разошлись. Знак подгоняется по `OneThing.bounds`, прямоугольнику его чернил в рамке 100 × 100: в строке меню он размером с системные значки: 16 pt высотой, а если от этого выходит шире 20 pt, то 20 pt шириной (кавычки 20 × 15 pt), на холсте 22 pt, на иконке занимает 80% плитки. Картинка с текстом фразы той же высоты, 22 pt, и текст стоит на базовой линии системного текста строки меню.

После правки знака иконку пересобирает `swift scripts/make_icon.swift`.

## Сборка

```sh
swift build && swift test            # тесты не трогают строку меню и ничего не регистрируют
./scripts/build_app.sh               # build/One Thing.app, универсальная сборка
ARCHS=arm64 ./scripts/build_app.sh   # быстрее, только для этого Mac
```

`build_app.sh` подписывает приложение сертификатом «tihomirov-nick» (SHA-1 `AF82036140843A7D76497EA8E4CD23403C8AEDC2`), если он есть в Связке ключей, иначе ad-hoc. Установленная копия обновляется только до версии с той же подписью.

Тексты интерфейса пишутся по-русски через `L("…")`, русская строка служит ключом. Английский перевод лежит в `scripts/l10n/en.json`, из него `scripts/l10n/make_strings.py` делает `Resources/en.lproj/Localizable.strings`. Если у строки нет перевода, сборка падает, а `swift test` замечает это ещё раньше.

`swift run OneThing --render-previews /tmp/preview` рисует в один файл `preview.png` строку меню (фраза тремя шрифтами, длинная фраза, пустая со знаком, точка обновления), окошко с полем, настройки и список шрифтов. Ничего не показывается на экране и не записывается в настройки.

## Выпуск

```sh
VERSION=1.0.0 ./scripts/make_dmg.sh                          # dist/OneThing-1.0.0.dmg
VERSION=1.0.0 NOTES=~/notes-1.0.0.md ./scripts/release.sh    # тег, push и релиз на GitHub
```

В DMG лежат приложение, ссылка на «Программы» и инструкции «Как установить.txt» и «How to install.txt». Приложение открывают прямо из окна DMG, и оно само переезжает в «Программы». `release.sh` собирает только закоммиченный код ветки main, берёт токен из Связки ключей (аккаунт `tihomirov-nick`, сервис `github-onething-token`) и выкладывает релиз в `tihomirov-nick/onething`. Git ходит туда по HTTPS: скрипт сам прописывает `origin` и помощника учётных данных с тем же токеном, потому что глобальный помощник git настроен на другой аккаунт. Перед push он проверяет, что приложение в DMG подписано «tihomirov-nick». Версия по умолчанию записана в `build_app.sh` и `make_dmg.sh`.

## Общие файлы семьи

Эти четыре файла одинаковы во всех приложениях семьи, байт в байт. Их правят в Subline и разносят копированием со сверкой sha256.

- `Sources/OneThing/Updater.swift` ищет новый релиз на GitHub при запуске, раз в три часа и после пробуждения Mac. Новую версию он ставит сам, когда приложение свободно (`appIsBusy`), или предлагает её (`freshOffer`). Перед установкой сверяет подпись скачанной версии с подписью установленной.
- `Sources/OneThing/Updater+Placement.swift` переносит копию, открытую из DMG или «Загрузок», в /Applications (без прав администратора в ~/Applications) и перезапускает её оттуда.
- `Sources/OneThing/Updater+LoginItem.swift` включает запуск при входе через `SMAppService` один раз для копии в «Программах», дальше решает пользователь. `LoginItem.launchedAtLogin` говорит, что приложение открылось при входе в систему.
- `Sources/OneThingCore/InterfaceLanguage.swift` хранит язык интерфейса по стандарту семьи. «Как в системе», «Русский» и «English» пишутся в собственный `AppleLanguages` приложения, это та же настройка, что в Системных настройках. Чтение и запись делают `saved` и `save`, про перезапуск отвечают `needsRestart` и `relaunch`.

Общее для семьи, но со своими текстами: `SoundEffects.swift` (системные звуки семьи и переключатель «Звуковые эффекты»), `Updates.swift` (состояния обновления, точка на значке и карточка в окошке), `SettingsWindow.swift`, `StatusItem.swift`, `MainMenu.swift` (невидимое главное меню с «Правкой», чтобы в полях работали ⌘C, ⌘V, ⌘A и ⌘Z) и `Style.swift`.
